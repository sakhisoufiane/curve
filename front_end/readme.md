# Curve

This is the front end Angular application for Curve.

## Getting Started

Node version 14.18.3

### Prerequisites

Install these before starting:

```bash
Node 14.18.3
```

### Installing

Install packages

```bash
npm install
```

### Running

To run the application (with minification)

```bash
npm start
```

To run the application as a dev build (without minification)

```bash
npm run start:dev
```

To build the application for production (adds minification)

```bash
npm run build
```

For development, this command runs the application and rebuilds *app.js* (without minification) when Angular source files are modified

```bash
npm run serve
```
