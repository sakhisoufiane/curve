Inherit Catalogue

You can use this feature to inherit catalogue from an associated client. Selecting the clients below will automatically copy all catalogue from the client associated client, and update all fields on save.

If you specify a catalogue group, only items associated with that group will be copied, leaving blank will copy all catalogue. Do ensure the wording and casing matches the catalogue group exactly.
